# EduReg — мобільний застосунок для реєстрації учасників освітніх заходів

Фронтенд навчального проєкту (лабораторна робота № 6–7, дисципліна «Професійна практика програмної інженерії»).

**Демо:** https://ivankrutyi23.github.io/edureq/

У демо застосунок показано в рамці смартфона: можна вибрати пристрій (iPhone, Pixel, Galaxy, iPad, ноутбук),
повернути екран, увійти за однією з ролей (учасник, організатор, адміністратор) або відкрити застосунок
повноекранно чи на власному телефоні (QR-код у демо-сторінці).

## Можливості

| Роль | Функції |
|---|---|
| Учасник | пошук і фільтри заходів, картка заходу, реєстрація та скасування, QR-квиток, історія |
| Організатор | створення й редагування заходів (валідація), список учасників, check-in за QR (імітація камери), ручне відмічання, статистика з діаграмами, експорт CSV |
| Адміністратор | керування користувачами та ролями, блокування, модерація заходів |

## Технології

React 18 · TypeScript · Vite · React Router (HashRouter) · Framer Motion (анімації) · Lucide (піктограми) · qrcode.react · шрифт Inter.

Дані — **фейковий REST API** (`src/api/mockServer.ts`) із тими самими кінцевими точками, що й майбутній бекенд на FastAPI;
стан зберігається в `localStorage`. Для підключення справжнього сервера достатньо задати змінну `VITE_API_URL`.

## Запуск

```bash
cd frontend
npm install
npm run dev        # розробка: http://localhost:5173
npm run build      # збірка у каталог ../docs (його публікує GitHub Pages)
```
